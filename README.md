# Nothing Store

A minimalist black and white website that sells absolutely nothing.

Visit the live site: [Nothing Store](https://vercel.com)

## 📂 Project Structure

- `nothing-store/` - The main website (pure HTML, CSS, JavaScript)
- `index.html` - Root redirect to nothing-store
- `vercel.json` - Vercel deployment configuration

## 🚀 Deploy to Vercel

This project is configured for easy Vercel deployment:

```bash
vercel
```

Or configure in Vercel dashboard with:
- **Root Directory**: `nothing-store`
- **Framework**: Other (static site)
